**`usage.json` of the reference campaign, derived by hand.** The seven evaluation events are
charged 1, 1, 1, 1, 0, 0, 1 (04-05), so `evals` is 5; the table backend costs no compute, so
`cpu_hours` is 0.0; no provider is called before Phase 6, so `tokens` is 0 and `usd` is 0.0;
`schema_version` is 1 (D-39). Rendered by `jsonio.pretty_bytes` - indent 2, sorted keys, item
separator `,`, key separator colon and space, one trailing LF - the file is seven lines and 89
bytes, sha256 `bb11fcba3db73cf823941bb629dd5827a614f908f7a40ba2f9284e0817787caa`:

```
{
  "cpu_hours": 0.0,
  "evals": 5,
  "schema_version": 1,
  "tokens": 0,
  "usd": 0.0
}
```

Byte count, line by line with the LF: 2 + 20 + 14 + 23 + 15 + 13 + 2 = 89. With the key
separator written without its space the same mapping would be 84 bytes; the pin therefore checks
the separator that plan 04-01 fixes in `pretty_bytes`.
