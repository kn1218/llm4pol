## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Hugging Face Hub → `data/raw/` | Bytes arrive from the network through `hf_hub_download`; the library never verifies content against the LFS sha256 (Q5) |
| `data/MANIFEST-open.sha256` → `fetch` | A committed text file decides which bytes are accepted; a wrong hash accepts a wrong file |
| CSV → loader | 259 columns of untrusted text; a column that looks numeric but is a `/`-joined string (F-41) would corrupt the dtype map |
| SMILES → RDKit | Arbitrary strings parsed by a C++ library; failures must be counted, never raised |
| `--root` CLI argument → filesystem | Paths are built under a user-supplied root; filenames are constants |
| conda-forge → `env/pixi.lock` | Two new packages enter the locked environment |
| tests → real repository | The real-file fixtures read the pinned file; nothing may write into `data/processed/` or `docs/audit/` of the real repository from a test |
