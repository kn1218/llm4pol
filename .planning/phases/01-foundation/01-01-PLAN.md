## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local history → public remote | The push to `origin main` publishes every reachable commit of a public repository; a secret in any commit, current or deleted, is disclosed on push (R-3, charter §12) |
| scanner output → console, CI logs, evidence file | Scanner output is printed, captured by CI and pasted into `01-EVIDENCE.md`; a value printed here is a value leaked (R-3) |
| test fixtures → real repository | Temp-repo tests run `git` with synthetic secrets; a fixture that escapes `tmp_path` would seed the real history with a hit |
| CI checkout → history scan | The scan is only as deep as the clone; `actions/checkout` defaults to depth 1 |
